## Icons

`icon:` takes a bare name, a prefixed name, or a file:

```yaml
icon: postgresql           # finds the logo
icon: logos:redis          # explicit set
icon: simple-icons:keycloak
icon: lucide:server        # generic UI icons
icon: ./assets/billing.svg # your own SVG, relative to the diagram folder
```

Bare names look in coloured **brand logos** first, then monochrome brand marks, then Lucide. Common shorthands work (`postgres`, `k8s`). Icons are bundled at build time, so nothing is fetched in the browser.

Not sure of a name?

```sh
pnpm docspp icons search redis
```

An unknown icon produces a warning with suggestions. Nodes without an `icon` use the icon of their `kind`: `client`, `user`, `ui`, `external`, `service`, `gateway`, `worker`, `container`, `function`, `database`, `cache`, `storage`, `queue`, `agent`, `network`, `vm`, `auth`, `monitor`. Add your own:

```yaml
kinds:
  ledger: { icon: lucide:book-open, family: amber }
```

## Colour families

A node's `family` (`blue`, `amber`, `violet`, `green`, `teal`, `red`, `slate`) sets its accent stripe and icon tint. Kinds choose one for you; set `family:` on a node to override.

## Theme

Diagrams follow the site's light and dark mode. To restyle them, override tokens in `src/styles/custom.css`:

```css
.docspp {
  --docspp-accent: #7a4ec4;     /* highlights, active steps, packets */
  --docspp-zone: #eef0f6;       /* zone background */
  --docspp-sans: 'Inter', system-ui, sans-serif;
  --docspp-dim: 0.7;           /* how faded unrelated items get while you focus or play (1 = no fading) */
}
:root[data-theme='dark'] .docspp {
  --docspp-accent: #b79bf0;
}
```

The full list of tokens is at the top of `packages/react/src/styles.css`.
