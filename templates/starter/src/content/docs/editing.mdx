Every diagram is a folder under `diagrams/`. Save a file and the page reloads.

```sh
pnpm docspp new payments      # creates diagrams/payments/diagram.yaml
pnpm check                   # validates every diagram; errors point at file:line:column
```

Show it on any page:

```mdx
import Diagram from '@docspp/astro/Diagram.astro'

<Diagram name="payments" />
```

## Boxes and arrows

```yaml
nodes:
  api: { kind: service, icon: nodejs, title: Orders API, sub: ":4002" }
  db:  { kind: database, icon: postgresql, title: PostgreSQL }

edges:
  - api -> db: { kind: data, label: SQL }
```

`kind` picks a default icon and colour. `icon` takes a name like `postgresql`; find one with `pnpm docspp icons search redis`. Put what a reader should see when they click a box in `diagrams/<name>/nodes/<id>.md`.

## Stories

A scenario is a story that plays over the diagram:

```yaml
scenarios:
  load-orders:
    title: Load my orders
    steps:
      - api -> db: { label: SELECT, kind: lookup }
      - db -> api: rows
      - at api: { label: build the response, note: Why this step matters. }
```

Group steps into `phases:` for longer stories, give failures their own scenario, and put long ones in `scenarios/<id>.yaml`.

Every scenario can also be read as a swimlane **story** (the *Story* button above the diagram). Give steps a `title` and a `detail` to write it up, and set `mode: story` on a scenario to open it that way.
