## Adding yourself

When your first pull request is merged, add a line to the list above in the same format, or ask in the pull request and a maintainer will add it for you:

```md
- Your Name ([@your-github-handle](https://github.com/your-github-handle)): what you worked on
```

Every kind of contribution counts, not only code: bug reports with a good reproduction, documentation, design, review, answering questions and translations.

The [contributors graph](https://github.com/AhmeddBasemm/docspp/graphs/contributors) on GitHub always has the complete commit history. Read [CONTRIBUTING.md](CONTRIBUTING.md) to get started.
